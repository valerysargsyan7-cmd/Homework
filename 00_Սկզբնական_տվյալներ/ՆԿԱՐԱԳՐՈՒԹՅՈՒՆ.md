# Սկզբնական տվյալներ

Այս պանակում պահվում են սկզբնական նյութերը, որոնցից վերականգնվել են ծրագրերի հասանելի ֆայլերը։

- `Git_օբյեկտներ`-ում կան Git-ի սեղմված օբյեկտներ. դրանք սովորական տեքստային ֆայլեր չեն։
- `index.txt`, `config.txt` և `COMMIT_EDITMSG.txt`-ը Git պահոցի մետատվյալներ են։

Այս նյութերը չեն ջնջվել, որպեսզի հետագայում հնարավոր լինի վերականգնել նաև այժմ չհասանելի մասերը։
