# Գործընթացներ և POSIX

Այս պանակում են Linux/POSIX միջավայրի C օրինակները.

- `basic` — գործընթացների ստեղծում, պանակ/ֆայլերի աշխատանք, զուգահեռ հաշվարկ և `dup`-ով ելքի վերահղում։
- `IPC/communication/Byte_stream/pipe` — խողովակներով տվյալների փոխանցում և հրամանների շղթա։
- `IPC/communication/Memory/Memory_mapping` — `mmap()`-ով ֆայլի հիշողային քարտեզավորում։
- `IPC/signal/standard_signal` — ազդանշանների դիմակ և երեխա-գործընթացի ժամանակային սահմանափակում։

Որոշ վարժություններից պահպանվել է միայն `Makefile` կամ `README.md`, իսկ մյուսներից՝ `main.c`։
