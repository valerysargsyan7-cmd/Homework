# Integer Echo

A simple C program demonstrating standard console input and output handling using `printf` and `scanf` with input validation.

## Description

This program prompts the user to input a single integer from the standard input (`stdin`), validates whether the input is indeed a valid integer, and then displays the entered value back to the console.

## Features

- Interactive command-line prompt.
- Input validation to catch non-integer values.
- Standard C17 compliant code.

## Requirements

- C Compiler (`gcc` or `clang`)
- `make` utility
